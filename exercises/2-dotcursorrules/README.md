# 2. Styling and Code-Quality Rules with `.cursorrules`

**What to Do**

1. In your project workspace, create a file named `.cursorrules`.
2. Define coding guidelines such as naming conventions, docstring requirements, or formatting standards. For instance:
   - Functions must use snake_case.
   - Include docstrings for all functions.
   - Enforce a specific line length.
3. Write a short piece of code (e.g., a simple Python script) that does not yet follow these guidelines.
4. Use **Cursor** to refactor the code by applying your `.cursorrules` style guide.

**Expected Outcome**

- An updated code snippet that conforms to the style rules specified in your `.cursorrules` file.
- Familiarise yourself with:
  - Create and configure a `.cursorrules` file.
  - Use **Cursor Autocomplete** and **Cursor Chat** to automatically enforce or fix style issues.

**Hint**

- Check https://cursor.directory/ for suggested rules
- Experiment with different rules (function docstrings, file headers, or naming patterns) and watch how Cursor adjusts the code.
- Add a rule to greet you with a funny quote before each answer
- Ask the AI in **Cursor Chat** to explain why certain changes are made.
