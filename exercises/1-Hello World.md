# 1. “Hello World” with Autocomplete & Basic Prompting

**What to Do**

1. Create a new file (e.g., `hello.py`) in Cursor.
2. Start typing `print("Hello W` and observe how Cursor suggests completions.
3. Use the **Cursor Chat** to ask the AI to add a simple feature: for instance, prompting the user for their name and printing a personalized greeting.
4. Test the script by running it locally.

**Expected Outcome**

- A fully functional “Hello World” script that can take a user input and print out a greeting (e.g., "Hello, [username]!").
- Attendees become comfortable with:
  - How **Cursor Autocomplete** suggests code completions.
  - How to use the **basic prompt** in **Cursor Chat** to make small iterative changes.

**Hint**

- If you get stuck or want a quick fix, open the chat and type: “Can you help me add a user input prompt and personalized greeting?”
- Then ask the AI to explain what was done so you understand the changes.
